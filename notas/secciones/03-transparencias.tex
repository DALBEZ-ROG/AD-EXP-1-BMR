Un servicio web oculta varias cosas al cliente. Oculta el acceso: Angular, hecho en TypeScript, y un cliente SOAP en Java le hablan al mismo backend Spring Boot. Oculta la ubicación, porque el cliente usa un nombre y no la IP del servidor. Oculta la replicación: según AWS, el nombre de la API de DynamoDB apunta a varios balanceadores con pesos y el cliente no escoge la máquina \cite{aws2025}. También oculta la concurrencia, porque muchos estudiantes consultan su estado a la vez sin verse.

Lo que no oculta es el fallo. Cuando algo se cae, el cliente recibe un \emph{timeout}, un error 5xx o un SOAP Fault y tiene que decidir qué hacer. En octubre de 2025 se vio claro: el registro DNS de DynamoDB quedó vacío, el servicio seguía funcionando, pero ningún cliente lo encontraba \cite{aws2025}.
